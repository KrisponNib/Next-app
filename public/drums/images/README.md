# תמונות

שמים פה את התמונות, ואז מעדכנים את הנתיב בקובץ `content.js`.

- `hero.png` - התמונה הראשית. הכי טוב PNG גזור בלי רקע
- `portrait.jpg` - תמונת פנים לכרטיס
- `full.jpg` - תמונה לאורך, גוף מלא
- `gallery-01.jpg` וכו' - תמונות לגלריה

טיפ: להקטין תמונות לרוחב של עד 1600 פיקסלים לפני שמעלים, שהאתר יעלה מהר.
