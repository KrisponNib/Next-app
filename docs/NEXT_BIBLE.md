## What NEXT is

NEXT is a Personal Chief of Staff.

It is **not**:
- a Todo App
- a Habit Tracker
- a Dashboard
- a Productivity App
- a Second Brain

NEXT exists for one reason: to help creative professionals build the career
they actually want.

The first user is Omri. Everything is built for him first. If the product
becomes amazing for him, only then does it become a platform for other
musicians, teachers, and creators.

## Product Philosophy

NEXT should reduce cognitive load. Not increase it.

Opening NEXT in the morning should feel calm. The user should never wonder
"What should I do now?" NEXT should answer that question immediately.

At night, NEXT should answer another question: "How did I actually move
forward today?"

## Core Principles

- One screen = one purpose.
- Simplicity over features.
- Silence is a feature.
- No feeds.
- No clutter.
- No dashboards.
- No fake progress.
- Recommendations must always explain why.
- Every action should create learning.
- Every reflection should improve future recommendations.
- The user always makes the final decision.

- Wins

## Design Language

Design should feel like Apple. Not visually copied — emotionally.

Characteristics:
- Calm
- Spacious
- Minimal
- Hebrew First
- RTL First
- Typography first
- One primary action per screen
- Warm white backgrounds
- Very little color
- No unnecessary icons

## Engineering Rules

- Never add features.
- Never remove features.
- Never redesign UX.
- Never redesign navigation.
- Never create dashboards.
- Never add charts.
- Never add gamification.
- Never over-engineer.
- Never optimize prematurely.
- Write clean, maintainable code.
- Think like a Staff Engineer.
- Optimize for long-term maintainability. Not for speed.

## Goal

We are not building an app. We are building a product that Omri will open
every morning instead of Instagram. If we achieve that, everything else can
be built on top of it.
