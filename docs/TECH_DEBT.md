# חובות טכניים

רשימה של דברים שידועים כבר עכשיו כלא-אופטימליים, אבל לא נכון לתקן אותם
היום - כי המוצר עדיין לא התייצב, ותיקון מוקדם מדי הוא בזבוז.

- **חילוץ הטקסט העברי הקבוע.** כרגע כל הכותרות, התוויות והפסקאות כתובות
  ישירות בתוך קבצי הרכיבים (למשל בכל קובץ תחת `features/` ו-`app/`).
  כשהמוצר יתייצב, יש להוציא את כל הטקסט הזה למקום מרוכז אחד ב-`lib/copy`,
  כדי שאפשר יהיה לשנות נוסח בלי לחפש בין קבצי קוד, ובעתיד גם כדי לפתוח
  את הדלת לתרגום לשפה נוספת אם יהיה בכך צורך.
