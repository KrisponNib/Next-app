# Next

שלד שלב א' - Next.js + React + TypeScript + Tailwind. אחסון מקומי בלבד, בלי סופאבייס.

## הפעלה

```bash
npm install
npm run dev
```

האפליקציה תיפתח על `/today`. המסכים `practice`, `reflect`, `wins`, `money`, `profile`
עדיין לא קיימים בשלב הזה בכוונה - התפריט התחתון מקשר אליהם אבל הם יחזירו שגיאת
עמוד לא נמצא עד שיבנו.

## תחזוקה

```bash
npm run lint          # בדיקת קוד
npm run format        # עימוד אוטומטי
npm run format:check  # בדיקת עימוד בלי לשנות קבצים
```

## מבנה וארכיטקטורה

ראה `docs/ARCHITECTURE.md` למבנה התיקיות ואסטרטגיית המצב והאחסון,
`docs/NEXT_BIBLE.md` למסמך היסוד המוצרי, ו-`docs/TECH_DEBT.md` לחובות
טכניים ידועים.
